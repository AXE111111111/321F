# 2011 年东日本海啸（Tohoku Tsunami）项目导读

2011 年 3 月 11 日，日本东北地区发生地震并引发海啸。NOAA 的 DART 海底压力监测记录可以帮助判断海啸何时抵达海上观测站。本项目用这些记录检验简化波动模型对海啸传播时间的解释能力。

> **核心问题**：假设沿传播路径的海水深度恒定，一维浅水波模型能否在预先设定的误差范围内，解释这次海啸抵达一个 NOAA DART 观测站所用的时间？

观测站、模型参数、数值格式和误差容差在正式调查时确定。

## 最终报告顺序【必做】

### 1. 问题陈述（Problem statement）

最终报告须回答 Week 10 **question memo** 中的七个问题。

1. 为什么要研究这个问题？谁会用到答案？
2. 用观测量表述主问题，避免在主问题里指定数值格式。
3. 有哪些测量和 **metadata**？哪些信息缺失或不确定？
4. 最简合理的 **initial–boundary value problem (IBVP)** 是什么？它省略了哪些机制？
5. 用什么 **quantity of interest** 回答主问题？说明两种可能的结果及其含义，例如到时误差在容差内或超出容差。
6. 哪项观测会使模型或结论站不住脚？
7. Weeks 11–13 能完成什么？如果原问题超出可行范围，更窄的备用问题是什么？

### 2. 数据来源与到达判定（Data and arrival detection）

- 选取一个震源记录和一个接收站。根据 [NOAA/NCEI DART 数据及 metadata](https://www.ngdc.noaa.gov/hazard/dart/2011honshu_dart.html) 记录站点 ID 或坐标、传感器和精确时间区间。
- 说明原始底压、拟合潮汐和去潮后的水柱高度残差各表示什么。统一时间基准（例如 UTC），明确震源时刻、采样间隔、到达阈值及缺失数据处理。
- 归档下载文件，记录数据集标题、机构、永久链接或 DOI、版本或站点／事件 ID、访问日期、许可条款、文件名、校验值、单位和处理步骤。

### 3. 波动模型与比较方式（Model and comparison）

- 建立一维恒深波动模型：`η_tt = gH η_xx`，波速 `c = √(gH)`，其中 `η` 为水面位移、`H` 为水深、`g` 为重力加速度。
- 说明传播路径和计算域、参数与单位、理想化的初始水面及其变化率、初边条件相容性，以及采用辐射边界还是足够远的边界。
- **推荐路线**为 **prediction test**。用独立于该站到时的水深或波速，检验计算到时是否落在预设容差内。
- **条件必做**：若用同一条到时记录反推水深或波速，须将结果表述为 **conditional inference**，并给出在不同路径长度、震源时刻和到达阈值假设下的估计范围。

### 4. 两种数值格式（Numerical schemes）

- 从 PDE 推导两种格式并解释选择理由。给出更新公式、初值与边界条件的离散处理，以及多步格式的 **start-up**。
- **条件必做**：使用库函数时，交代团队负责的推导和验证、库调用的适用理由、选项及相关 **solver tolerances**，并检查容差低于要测量的误差。
- **条件必做**：若两种格式都通过库调用实现，记录至少一项团队主动调整及其测得的影响。

### 5. 验证、收敛与稳定性（Verification, convergence and stability）

- 用一个具有 **exact or manufactured solution** 的平滑波算例验证两种格式，再做一个有意设置难点的 **stress test**，例如高频波或长时间传播。
- 分别做空间和时间加密。估计空间收敛阶时压低时间误差，估计时间收敛阶时压低空间误差。说明各组固定量、误差范数和测得的收敛阶。
- 根据实际网格、格式和边界处理选择稳定性分析方法。常系数且满足 Fourier 分析条件时可采用 **von Neumann analysis**。有边界的波动问题可采用适用的 **matrix** 或 **energy argument**。
- 设计一个可能推翻稳定性判断的数值实验。若格式有推导得到的有限稳定限制，给出 **CFL condition**。若格式无有限限制，给出适用的无条件稳定性估计。

### 6. 波动保真度与计算成本（Fidelity and cost–accuracy）

- 至少量化一项波动诊断：**energy** 或单一模态的长期 **phase error**。
- 设定共同的精度目标，实测并比较两种格式达到该目标所需的计算成本。注明成本指标，例如运行耗时、迭代次数或操作次数。

### 7. 观测对照、局限与复现（Results, limitations and reproducibility）

- 给出观测到时、计算到时和时间残差。统一单位，按「计算值减观测值」报告残差，依据预设容差回答主问题。
- 结合数值验证，解释离散误差与模型偏差，并讨论采样、去潮处理、恒定水深、一维传播、简化震源和省略近岸相互作用如何影响结论。若用大圆距离作路径长度，说明它与实际传播路径可能存在的差别。
- 将结论限定在简化模型的评估范围内。提供一条可复现实验的命令，并以最能减少不确定性的下一项测量或实验收尾。

## 建议扩展【选做】

一站、恒深的一维模型即可完成基础范围。验证核心工作后，可选择最能帮助回答主问题的扩展。各级范围均适用上述数值验证要求。

1. **Sensitivity analysis**：优先比较水深、震源时刻、传播路径、采样间隔和到达阈值，找出哪些因素可能改变结论。
2. **第二个接收站**：检验结论是否适用于另一条路径。若用第一站拟合水深或波速，保留第二站作独立检验。
3. **波动诊断**：补做另一项保真度诊断，在多个周期上比较 **energy** 和 **phase error**，或将离散 **dispersion relation** 与 `ω = √(gH) k` 对照。两种稳定格式的相位差可作为次要问题。
4. **物理模型扩展**：尝试 **variable bathymetry** 或二维传播。通用 problem pack 中的 **leapfrog** 格式和正弦波参考解可作为独立的数值验证备选方案。
